> **精准计算双属性克制，制霸洛克对战！**

## 📖 项目简介

还在为《洛克王国》复杂的属性克制关系头疼吗？面对双属性精灵总是算不准伤害倍率？

**属性克制倍率矩阵**是一款专为洛克玩家打造的 **交互式属性克制查询工具**。它不仅能让你一目了然地看到所有单属性间的克制关系，更能**智能计算双属性精灵的合成倍率**（如×4、×0.25），是你征战天梯赛、挑战BOSS的必备神器！

## ✨ 核心亮点

- **🔥 双表合一，攻防兼备**：集成【攻击视角】和【防御视角】两张热力图矩阵，无论是你打别人，还是别人打你，都能秒查倍率。
- **🧠 智能双属性合成**：只需点击选择我方和对方的属性（支持1~2个），系统即刻自动计算并高亮显示最终的合成伤害倍率，省去手动计算的烦恼。
- **🎯 实时高亮，一目了然**：选中属性后，对应的行和列会立即高亮，让你在庞大的数据表中瞬间定位到所需信息。
- **💡 悬停详解，知其所以然**：鼠标悬停在任意倍率格子上，会弹出详细的计算公式和步骤，让你不仅知道结果，更懂背后的逻辑。
- **📱 多端适配，随时随地**：完美支持电脑和手机访问，并针对手机横竖屏做了专门优化，无论何时何地都能轻松查询。
- **🌐 国际化支持**：内置中英文切换功能，满足全球玩家的需求。

## 🚀 如何使用

1. **打开页面**：
   - **在线体验**：[点击此处](https://antonygith.github.io/RocoElementalAffinityChart/)（如果已部署 GitHub Pages，请替换为实际链接）
   - **本地运行**：克隆仓库后，直接用浏览器打开 `index.html` 文件（即本仓库根目录下的 HTML 文件）。

2. **选择属性**：
   - 在左侧“选择我方精灵属性”区域，点击1~2个属性按钮（再次点击可取消选择）。
   - 在右侧“选择对方精灵属性”区域，同样选择1~2个属性（也可不选，表格将按单属性列展示）。

3. **查看结果**：
   - **攻击视角表**：行代表我方属性，列代表对方属性，格子内的数字即为伤害倍率。
   - **防御视角表**：行代表我方属性，列代表对方属性，格子内的数字为你方承受的伤害倍率。

4. **获取详情**：将鼠标移动到任意倍率格子上，即可查看该倍率的详细计算过程。
