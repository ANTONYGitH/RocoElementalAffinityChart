# 洛克王国属性克制/抵抗倍率矩阵（双表 · 双属性 · 9 语言）

> 一个单文件 HTML 的属性克制速查工具：选属性 → 看倍率，3 秒出结果。
> 18 属性 × 双属性组合、攻击/防御双视角矩阵、9 种语言、离线可用、手机电脑通用。

## 📖 使用步骤

1. **选择我方精灵属性**：在「我方属性」区点选 1～2 个属性（支持双属性）。
2. **选择对方精灵属性（可不选）**：在「对方属性」区点选 0～2 个属性；不选时只看单属性倍率。
3. **查看克制关系**：弹窗与下方「攻击视角 / 防御视角」表格实时高亮显示倍率。
   - 🔴 ×4 双克制 ／ 🟠 ×2 克制 ／ ⚪ ×1 普通 ／ 🟢 ×0.5 抵抗 ／ 🔵 ×0.25 双抵抗

> 右上角工具条：🔒 锁定、🌐 切换语言、ℹ️ 作者、🕘 历史记录、⤴ 分享、💻/📱 视图切换。

## 💻 技术说明

- 纯前端单文件：HTML + CSS + 原生 JS，无构建、无外部依赖（图标/二维码已内联为 base64）。
- 倍率算法：`atk2` / `atk05` 克制表 → 默认 ×1 → 写 ×2 → 仅空位写 ×0.5（×2 优先）；双属性按对相乘合成。
- 防御矩阵继承攻击矩阵，仅覆盖光、冰两行的特殊关系。
- 兼容：任意现代浏览器；移动端自适应；双击文件即可离线运行。
